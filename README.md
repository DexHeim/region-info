# Region Info

Справочник по онлайн-игре Region с локальной базой из обновлённой [Region Wiki](https://wiki.region.game/). Импортированы 6 588 подробных страниц, 74 статьи о механиках и все 16 разделов. В каталогах есть поиск, фильтры, сортировка и пагинация. Транспорт содержит 321 модель и сравнение до четырёх моделей. Карта содержит 498 мест и 193 зоны с фильтрами, поиском, масштабированием и перемещением.

Наши расчёты тюнинга находятся в карточках транспорта и в отдельном калькуляторе. Прежний каталог на 146 машин с дополнительными замерами управляемости и торможения доступен в `cars.html`.

Характеристики и салонные цены прежнего каталога синхронизируются с Wiki по коду модели. Управляемость и торможение содержат собственные замеры. Проверенные замены отсутствующих изображений перечислены в `data/wiki/image-overrides.json` и применяются в каталогах и подробных карточках.

Расчёт тюнинга приблизительный: он основан на фактических ценах BMW M5 (E39) стоимостью 1 700 000 ₽. Улучшения и внешний тюнинг масштабируются пропорционально цене автомобиля и округляются до 100 ₽, а цены клаксонов одинаковы для всех автомобилей. Улучшения имеют минимальную стоимость 10 000 ₽. Итог «Все улучшения» включает покупку каждого уровня по порядку, а не только максимальных уровней.

Самостоятельный калькулятор принимает цену автомобиля в салоне или государственную стоимость и показывает цены всех улучшений, вариантов окраски, тонировки, колёс, фар и клаксонов. В карточке транспорта расчёт использует салонную цену Wiki. Для моделей без салонной цены стоимость можно ввести вручную.

## Обновление базы Wiki

```powershell
python scripts/import_wiki.py --refresh
```

Импортёр на стандартной библиотеке Python обходит публичные каталоги, статьи и связанные карточки, извлекает данные компонентов и сохраняет содержимое в `data/wiki/`. Ссылки и источники записываются вместе с данными. Подробные страницы разбиты на небольшие части и загружаются при открытии. Изображения и тайлы карты загружаются с серверов Region. Исходные HTML-страницы кешируются в игнорируемом каталоге `spreadsheet-work/wiki-source/`. Флаг `--refresh` получает свежие страницы. Для продолжения прерванной загрузки запустите команду без этого флага.

## Данные из Google Sheets

Прежний каталог `cars.html` умеет загружать опубликованную Google-таблицу и автоматически переключается на локальный файл `data/cars.json`, если таблица недоступна. Новый каталог транспорта использует импортированную базу Wiki.

Готовый файл `outputs/region-auto/region-auto-cars.xlsx` содержит все 146 позиций. Его можно импортировать в Google Sheets через `Файл → Импорт → Загрузить`, чтобы не переносить строки вручную.

Лист должен называться `Автомобили`, а первая строка таблицы должна содержать точные имена колонок:

```text
id | name | dealer | fuel_l | fuel_unit | fuel_type | trunk_kg | max_speed_kmh | handling | acceleration_0_100_s | braking_100_0_s | price_rub | sprite_sheet | sprite_index | active
```

Правила заполнения:

- числа указываются без единиц измерения и знака валюты;
- `active` — `TRUE` для показа машины и `FALSE` для скрытия;
- `id`, `sprite_sheet` и `sprite_index` связывают строку с изображением транспорта, поэтому их лучше не менять;
- `dealer` — точное название автосалона, например `Автосалон 3/5`;
- заголовки колонок менять нельзя, порядок колонок не важен.

Откройте доступ к таблице по ссылке, возьмите её ID и сформируйте CSV-адрес:

```text
https://docs.google.com/spreadsheets/d/ID_ТАБЛИЦЫ/gviz/tq?tqx=out:csv&sheet=Автомобили
```

Вставьте адрес в `googleSheetCsvUrl` файла `assets/js/config.js`. После этого изменения в Google Sheets будут появляться на сайте при обновлении страницы.

## Публикация на GitHub Pages

Сайт публикуется из корня ветки `main`. В настройках репозитория используется источник `Deploy from a branch`, ветка `main`, папка `/ (root)`.

После каждого обновления ветки `main` GitHub Pages автоматически пересобирает сайт.
